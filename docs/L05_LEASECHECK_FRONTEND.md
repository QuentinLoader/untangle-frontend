# L05 — LeaseCheck frontend experience

The universal result route now handles two result contracts:

- TaxSnap (`module = TAX`)
- LeaseCheck (`module = LEASE`)

LeaseCheck renders the human-first sections agreed for Untangle:

1. What this is
2. What you are agreeing to
3. Important money
4. Important dates
5. Responsibilities in this lease
6. Clauses to pay attention to
7. Do this next
8. General protections that may matter
9. Where to get help
10. More details / sources

The UI labels document wording as **Your lease says** and keeps general legal context separate.

No customer-facing availability switch is included in L05 because L06 has no genuine lease benchmark evidence yet.
